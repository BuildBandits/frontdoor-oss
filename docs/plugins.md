# Frontdoor Plugin Host

> **Status:** the plugin platform is locked off in the current releases: plugin routes answer `404` and the server keeps the plugin setting off. The work required before unlocking it is tracked in [#90](https://github.com/BuildBandits/frontdoor-oss/issues/90).

The design (loader inputs, manifest and module contracts, runtime API, surfaces, server registry, package formats and audit trail) is documented on the web: [Plugins](https://frontdoor.buildbandits.com/docs/integrators/plugins/).
