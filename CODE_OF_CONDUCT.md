# Code of Conduct

Frontdoor adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

The full text is maintained upstream at the link above. By participating in this project — through issues, discussions, pull requests, or any other channel — you agree to abide by it.

## Scope

This Code of Conduct applies within all project spaces (repository, issues, pull requests, Discussions, release artifacts) and when an individual is officially representing the project in public spaces.

## Reporting

Reports of unacceptable behavior may be sent privately to the maintainers at:

`<conduct@TBD>` *(this address will be set when the project is migrated to its permanent home)*

All reports are reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and safety of the reporter.

## Enforcement

Maintainers are responsible for clarifying and enforcing this Code of Conduct. They may take any action they deem appropriate, up to and including temporary or permanent ban from project spaces, as outlined in the Contributor Covenant's enforcement guidelines.
