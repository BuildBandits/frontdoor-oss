## Contact

For project decisions, reviews, or maintainer-only matters, mention both handles in a GitHub issue, Discussion, or pull request. Security vulnerabilities go through GitHub's private vulnerability reporting first, as described in [SECURITY.md](SECURITY.md); see also [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) (conduct) and [TRADEMARK.md](TRADEMARK.md) (brand and trademark).
